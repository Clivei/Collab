# NORA Gemini v3 "Twin" - new mould, in-pattern design with a unique build

Higgsfield 3D project: https://higgsfield.ai/3d-jutsu/83e5a7ae-ea81-42a5-9b9d-88d5c05a5af1 (revision 1)

* `gemini_v3_shape.py` - new mould (not the traced OXDOG one): squared-shoulder diamond, one delta throat window, 104 staggered holes.
* `gemini_v3_art.py` - the design: both faces, materials, `build_v3()`.
* `hosted_blob.py` - the single script sent to the Higgsfield scene (v2 body builder + v3 shape + v3 art + stage + renders).
* `higgsfield_renders/` - renders from the hosted scene. `previews/` - local test render.

Stays in the market pattern: big centred wordmark through the holes, black base, one accent, model name above the throat.
Unique: the wordmark is a finish change with a laser keyline (not print); front and back invert finish and accent
(matte sand + crimson / gloss 16K aluminised + cobalt); eight holes carry laser rings (the Gemini stars); twin shoulder lines.
